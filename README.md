# 🧮 Calculatrice JavaScript — Infinite Points

Une petite calculatrice développée en JavaScript, accompagnée d'une animation visuelle de **points infinis descendant à l'écran avec CSS.

Ce projet a été réalisé pour pratiquer les bases de JavaScript, notamment les fonctions, les conditions, les boucles, les erreurs et les boîtes de dialogue natives du navigateur.

---

## 🚀 Aperçu

Le projet combine deux éléments :

- 🧮 Une calculatrice interactive en JavaScript
- ✨ Une animation de points descendant continuellement avec CSS
- ⏱️ Un délai de 4 secondes avant le lancement de la calculatrice
- 🔁 La possibilité de recommencer plusieurs calculs
- ⚠️ Une gestion des erreurs, notamment la division par zéro

---

## 🎯 Fonctionnalités

### 🧮 Calculatrice

La calculatrice permet d'effectuer quatre opérations :

| Opération | Fonction |
|---|---|
| ➕ Addition | Additionner deux nombres |
| ✖️ Multiplication | Multiplier deux nombres |
| ➖ Soustraction | Soustraire deux nombres |
| ➗ Division | Diviser deux nombres |

L'utilisateur choisit une opération, saisit deux nombres puis obtient le résultat.
